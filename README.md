# PFCかんたん計算ツール

食品を選んでグラム数を入れるだけ。カロリーとPFC（たんぱく質・脂質・炭水化物）をかんたんに合計できる、無料の計算ツールです。

## 使い方

1. 食品を選んで、量（g）を入れて「追加する」を押すだけ。
2. 今日の合計が、カロリー・たんぱく質・脂質・炭水化物ごとに表示されます。
3. 1日の目標値を入れると、達成率のバーで比較できます。
4. 一覧にない食品は「自分の食品を登録する」から、100gあたりの値を入れて登録できます（無料版は5件まで）。

入力したデータはブラウザ内（localStorage）にのみ保存されます。サーバーには送られません。

## 食品データについて

食品データは日本食品標準成分表（八訂）をもとにした概算値です（初版30品目）。調理方法や銘柄により前後します。プロテインは製品により大きく異なるため、代表的なホエイプロテインの目安値です。

## Proについて

Proでは次の機能が使えるようになります（準備中）。

- 毎日の記録を保存して、グラフでふり返る
- 体重や目的から目標カロリー・PFCを自動計算
- 登録できる食品の数を広げる
- 記録をCSVで書き出す
