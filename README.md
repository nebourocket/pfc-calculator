# PFCかんたん計算ツール

食品を選んでグラム数を入れるだけ。カロリーとPFC（たんぱく質・脂質・炭水化物）をかんたんに合計できる、無料の計算ツールです。減量・維持・増量など、目的に合わせてどなたでも使えます。

## 使い方

1. 食品を選んで、量（g）を入れて「追加する」を押すだけ。
2. 今日の合計が、カロリー・たんぱく質・脂質・炭水化物ごとに表示されます。
3. 1日の目標値を入れると、達成率のバーで比較できます。
4. 一覧にない食品は「自分の食品を登録する」から、100gあたりの値を入れて登録できます（無料版は5件まで）。

日付が変わると、前日までの合計は「過去の記録」に移ります（直近7日分を表示）。今日の記録は新しい日から空の状態で始まります。

## データの保存について（プライバシー）

- 記録はあなたの端末の中（ブラウザの localStorage）だけに保存されます。
- アカウント登録は不要で、データが外部に送られることはありません。
- このアプリはクレジットカードなどの決済情報を扱いません。お支払い情報は、将来の単体サブスクリプションを含め、決済事業者（Stripe）のページでのみ扱い、このアプリに保存されることはありません。

## 食品データについて

食品データは日本食品標準成分表（八訂）増補2023年をもとにした概算値です（初版30品目）。主要品目（ごはん・食パン・鶏むね肉・ささみ・鶏もも肉・鮭・卵・納豆・木綿豆腐）は文部科学省の食品成分データベースの値と照合済みです。調理方法や銘柄により前後します。プロテインは製品により大きく異なるため、代表的なホエイプロテインの目安値です。

## Proについて

基本の計算・目標比較・簡易履歴は無料で使えます。Proは「もっと便利になる追加分」です。

- 過去14日間の記録をグラフでふり返る（目標カロリーのライン付き）
- 目標カロリー・PFCの自動計算（下記の前提で算出）
- 自分の食品を200件まで登録できる
- 今日の記録と履歴をCSVで書き出す（BOM付きUTF-8、Excel対応）

### 自動計算の前提

- 基礎代謝（BMR）は Mifflin-St Jeor 式：男性＝10×体重(kg)＋6.25×身長(cm)−5×年齢＋5、女性＝同式−161。
- 1日の消費目安（TDEE）＝BMR × 活動レベル（1.2／1.375／1.55／1.725）。
- 目標カロリー：減量＝TDEEの−20%（ただしBMRは下回らない）、維持＝TDEE、増量＝TDEEの+10%。
- PFCの目安：たんぱく質＝体重×2g、脂質＝目標カロリーの25%、炭水化物＝残り。

あくまで一般的な目安であり、医療・栄養指導ではありません。
